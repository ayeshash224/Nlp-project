## Environment setup

The project uses a conda environment with **Python 3.12**. `gensim 4.3.3` needs `numpy < 2`, so the versions in `requirements.txt` are pinned together.

```
conda create -n imdb-nlp python=3.12 -y
conda activate imdb-nlp
pip install -r requirements.txt
python -m ipykernel install --user --name imdb-nlp --display-name "Python (imdb-nlp)"
```

In Jupyter, choose **Kernel → Change Kernel → Python (imdb-nlp)**.

## How to run

**Assignment 1** – create the cleaned dataset (once, about 20 minutes):
```
python cleaning_pipeline.py
```
Output: `data/cleaned_imdb_reviews.csv` (50,000 rows; `review_id`, `sentiment`, `cleaned_text`).

**Assignment 2** – train and save all representations (once, about 15 minutes):
```
python representations.py
```
Output in `models/`:

| File | Representation |
|---|---|
| `tfidf_vectorizer.joblib` | fitted TF-IDF vectorizer |
| `word2vec_cbow.kv` | Word2Vec CBOW word vectors |
| `word2vec_skipgram.kv` | Word2Vec Skip-gram word vectors |
| `fasttext.kv` (+ `.npy` files) | fastText word and character n-gram vectors |

**Notebooks** – open from this folder (`jupyter notebook`) and use **Kernel → Restart Kernel and Run All Cells**:

| Notebook | Time | Needs |
|---|---|---|
| `Member_1 L1F23BSCS0220.ipynb` | ~5 min | cleaned dataset |
| `Member_2 L1F23BSCS0581.ipynb` | ~15 min (trains 3 models) | cleaned dataset |
| `Member_3 L1F23BSCS0186.ipynb` | ~2 min (loads `models/`) | `models/` – created automatically if missing |

## Settings (same for every representation)

- Corpus: `data/cleaned_imdb_reviews.csv`, tokens split on spaces (exactly the Assignment 1 tokens)
- Count-based: `CountVectorizer` / `TfidfVectorizer` (default smooth idf, L2 norm)
- Embeddings: `vector_size=100`, `window=5`, `min_count=5`, `epochs=10`, `seed=42`; CBOW `sg=0`, Skip-gram `sg=1`
- fastText: character n-grams 3–6, `bucket=200000`

## Vectorize a document (interface for Phase 3)

```python
from vectorize import vectorize_document

vector = vectorize_document("This movie was not good!", representation="tfidf")
# representation: "tfidf", "cbow", "skipgram" or "fasttext"
```
The raw text is cleaned with `clean_review()` (Assignment 1), then:
- `tfidf` returns a sparse 1 × 142,754 vector
- `cbow`, `skipgram`, `fasttext` return the average word vector (100 numbers)

Models are only loaded from `models/`; nothing is retrained.
